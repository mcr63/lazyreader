lazyreader
==========

For CougarBoard readers, a way to read all the postings in a thread without loading each page.

## What changed recently

`lazyreader.js` was rewritten from jQuery to vanilla JavaScript for better Safari/iOS compatibility.

## Usage

1. Install a userscript extension (e.g., Tampermonkey).
2. Create a new userscript for `*.cougarboard.com`.
3. Paste in the contents of `lazyreader.js`.
4. Visit a CougarBoard thread page and hover a subject to load a preview.
